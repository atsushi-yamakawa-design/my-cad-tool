# projects/ — プロジェクト（1つの用途のための形）

靴べら立てのように、特定の用途のために作る形をここに置きます。1プロジェクト＝1ファイル（`<名前>.py`）。

- 書き方は `parts/` の部品と同じ（`@component` を付けた関数）。デザインの JSON、GUI のプロパティ、書き出しでそのまま使えます
- `parts/` と違って、GUI のパレット（コンポーネント集）には出ません
- ほかのデザインでも使い回したくなったら、`parts/` に移すと部品として登録されます

| ファイル | 中身 | デザイン |
|---|---|---|
| `shoehorn_stand.py` | 靴べら立て（3Dプリント） | `designs/shoehorn_stand.json` |
